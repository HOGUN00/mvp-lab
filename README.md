## 진행 단계

- [ ] 문제 정의
- [ ] 대상 사용자 정의
- [ ] MVP 범위 결정
- [ ] 핵심 정책 결정
- [ ] Acceptance Criteria 작성
- [ ] API / 데이터 모델 설계
- [ ] MVP 구현
- [ ] 배포
- [ ] 실제 사용 / 피드백 수집
- [ ] 개선
