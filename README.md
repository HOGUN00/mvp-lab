# mvp-lab

사용자 문제를 정의하고 MVP를 직접 설계·구현·배포하며, 해결에 필요한 기술을 빠르게 학습해 적용하고 실제 사용과 피드백을 바탕으로 개선하는 프로젝트.

## 진행 단계

- [ ] 문제 정의
- [ ] 대상 사용자 정의
- [ ] MVP 범위 결정
- [ ] 핵심 정책 결정
- [ ] Acceptance Criteria 작성
- [ ] API / 데이터 모델 설계
- [ ] MVP 구현
- [ ] 배포
- [ ] 실제 사용 / 피드백 수집
- [ ] 개선
